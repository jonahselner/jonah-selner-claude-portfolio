# Jonah's AI Portfolio

Working prototypes of the Claude skills, apps, and dashboards I built while running **Boost**, a patient engagement company for elective and specialty medical practices, plus a few other things I've built along the way.

Everything here runs on a **fictional version of Boost**: realistic in shape, entirely made up in content. There is no real patient, practice, or company data in this repo.

> Work in progress. Builds are added one at a time.

## What will live here
- **Skills:** Claude Skills (`SKILL.md` plus supporting files) recreated from real Boost workflows
- **Apps:** small web apps built with Claude Code
- **Dashboards:** examples wired to sample data sources stored in this repo
- **Portfolio page:** one hosted page that links to each piece
