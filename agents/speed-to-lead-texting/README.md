# Speed-to-lead texting agent

An AI texting agent that replies to a practice's web form leads within seconds, any hour, answers their questions from that practice's knowledge base, and hands them to a human scheduler once they're ready to book.

- [`master-prompt.md`](master-prompt.md): the shared prompt every practice runs on: voice, conversation flow, scope and hard limits.
- [`example-knowledge-base.md`](example-knowledge-base.md): one practice's facts and settings. The practice is fictional; the structure is the one we used in production.

Write-up: [jonah-ai-portfolio.vercel.app/speed-to-lead.html](https://jonah-ai-portfolio.vercel.app/speed-to-lead.html)
